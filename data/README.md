# Cohort FASTQs (local)

Place **two** paired-end FASTQ files here (`.fastq.gz` or `.fq.gz`). Point `samplesheets/cohort.csv` at these paths (see `samplesheets/cohort.csv.example`).

Shell helpers under `data/` (for example `*.sh`) are for local use only and are not part of the tracked dataset layout.
